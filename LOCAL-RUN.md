# USTA — локальный запуск

Откройте `http://localhost:3000`. После перезагрузки компьютера дважды нажмите
`START-USTA.cmd` в этой папке. Окно запуска должно оставаться открытым.
Для остановки нажмите Ctrl+C. Требуется Node.js 24; на этом компьютере скрипт
также находит встроенный в Codex Node.js.

## Рабочие функции

- Регистрация клиента и мастера, вход, выход, редактирование имени и описания.
- Заказ: категория, город, закрытый адрес, описание и бюджет в сумах.
- Лента открытых заказов города мастера, предложение цены и условий.
- Выбор мастера клиентом с фиксацией согласованной цены.
- Переписка, история событий, начало работы, сдача и подтверждение результата.
- Отзыв только от клиента завершённого заказа, рейтинг профиля по отзывам.
- Отмена клиентом до начала работы.
- Сохранение в SQLite, серверная проверка ролей, пароль scrypt, HttpOnly-сессии.
- Админка с реальными заказами, аккаунтами, отзывами и журналом действий.
- Блокировка/разблокировка аккаунтов и отмена открытых заказов с причиной.
- Карта ближайших мастеров и открытых заявок: радиус, услуги, расстояния,
  выбор места заказа и персональное предложение выбранному мастеру.

Подробности работы карты: [docs/MAP.md](docs/MAP.md). Для отображения подложки
нужен интернет; геолокацию можно заменить ручным выбором точки.

## Администратор

Вход: `http://localhost:3000/login`. Уникальный локальный пароль сохранён в
`ADMIN-ACCESS.local.txt`. Этот файл и `.env.local` не включаются в Git.
Аккаунт администратора отделён от клиента и мастера. Блокировка пользователя
отзывает его активные сессии. Модерация требует причину и сохраняется в журнале.
На новом компьютере первоначальные настройки создаёт `node scripts/setup-local.mjs`.

## Проверить полный сценарий

Для проверки через браузер уже созданы два **тестовых** аккаунта:

| Роль | Email | Тестовый пароль |
|---|---|---|
| Клиент | client@usta.local | UstaLocal-2026! |
| Мастер | master@usta.local | UstaLocal-2026! |

Они предназначены только для этой локальной версии. Собственный аккаунт можно
создать кнопкой «Найти мастера» или «Стать мастером».

1. Зарегистрируйте клиента, создайте заказ в Ташкенте.
2. В другом браузере или приватном окне зарегистрируйте мастера в Ташкенте.
3. Мастер открывает заказ и отправляет предложение.
4. Клиент выбирает предложение. Адрес становится доступен выбранному мастеру.
5. Обменяйтесь сообщениями. Мастер нажимает «Начать работу», затем «Работа выполнена».
6. Клиент нажимает «Подтвердить результат» и оставляет отзыв.

Данные обновляются каждые 12 секунд, также есть кнопка «Обновить».
Случайно введённые пароли нельзя восстановить: почтовый сервис не подключён.
Не используйте для тестовых аккаунтов пароль от других сервисов.

## База и резервная копия

База: `data/usta.sqlite` вместе со служебными файлами `-wal` и `-shm`.
Нельзя удалять эти файлы при работающем приложении. Данные не отправляются в Git.
Согласованная резервная копия работающей базы:

```powershell
node scripts/backup.mjs
```

Копия появится в `backups`. Для восстановления остановите приложение,
сохраните текущие файлы базы в отдельной папке и поместите выбранную резервную
копию по пути `data/usta.sqlite`; старые `-wal`/`-shm` не должны оставаться рядом.
После этого запустите приложение. Резервная копия содержит данные пользователей
и должна храниться приватно.

## Разработка и проверки

```powershell
pnpm install --frozen-lockfile
node --test tests/*.test.mjs
node node_modules/typescript/bin/tsc --noEmit
node node_modules/eslint/bin/eslint.js . --max-warnings=0
node node_modules/next/dist/bin/next build
node node_modules/next/dist/bin/next start --hostname 127.0.0.1 --port 3000
```

После изменений кода повторите сборку перед запуском. Сервер слушает только
этот компьютер. Для переноса на другой компьютер нужны исходники, зависимости
и резервная копия; `node_modules` и `.next` пересоздаются.

## Границы этой версии

Это локально работающий базовый маркетплейс, а не вся дорожная карта USTA 2030.
Оплата согласуется с мастером и происходит вне платформы; эквайринг, escrow,
гарантии, автономный AI-диспетчер, проверка личности, уведомления Telegram, почта и SMS
не подключены. Старые страницы прототипа перенаправляют в рабочие кабинеты.
Пользовательский кабинет находится на `/`, административный — на `/admin`.
Для публичного сервиса нужны отдельная настройка размещения, HTTPS, восстановление
аккаунтов, правила работы службы поддержки и интеграции. SQLite рассчитана на один постоянный сервер,
не на бессерверное размещение Vercel.

## ИИ-помощник и цены

Разделы «ИИ-помощник» и «Цены» находятся в кабинете. Поддержаны текст,
запись голоса, загрузка аудио, черновик заявки и сравнение согласованных
сумм завершённых заказов. Без OPENAI_API_KEY ИИ явно отключён.
Telegram-бот подготовлен к текстовым/голосовым диалогам, но требует токена
и собственного HTTPS-адреса. Инструкция: [docs/AI.md](docs/AI.md).
