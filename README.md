# USTA WebApp

USTA — от проблемы до результата. В этой локальной версии главная страница `/`
содержит рабочий маркетплейс: аккаунты клиента и мастера, заказы, предложения,
выбор исполнителя, чат, подтверждение выполнения и отзывы. Данные сохраняются
в SQLite. Добавлены карта, статистика цен и интеграция ИИ для текста/голоса.
ИИ требует серверного ключа OpenAI; без него экран показывает состояние
ожидания подключения. Платежи не подключены. Настройка и точные границы:
[docs/AI.md](docs/AI.md).

**Локальный запуск на Windows: `START-USTA.cmd` → http://localhost:3000.**
Полная инструкция, тестовые аккаунты и резервное копирование: [LOCAL-RUN.md](LOCAL-RUN.md).
Старые страницы прототипа перенаправляют в рабочие кабинеты. Основной сценарий
доступен на главной странице, админка с реальными данными и модерацией — на `/admin`.

## Запуск

Node.js 24 и pnpm 11.25.0:
```sh
corepack enable
corepack prepare pnpm@11.25.0 --activate
pnpm install --frozen-lockfile
node scripts/setup-local.mjs
pnpm dev
```
Для админки задайте ADMIN_PASSWORD (от 16 символов) и SESSION_SECRET
(случайное значение от 32 символов) либо используйте setup-local.mjs.
Без них вход закрыт. Не перезаписывайте существующий .env.local шаблоном.
Вход: /login, админка: /admin, выход: /logout.
Пароль по умолчанию отсутствует. Сессия подписана и действует час.
Смена SESSION_SECRET отзывает все сессии.

## Ограничения запуска

Проверка админки выполняется серверным layout. Каждый будущий API/Server Action
обязан отдельно проверять сессию и разрешение на операцию. Ограничитель входа
работает в памяти одного процесса; для production нужен общий лимитер/WAF.
Авторизация клиентов и мастеров реализована через email/пароль и сессии SQLite.
Проверка Telegram initData, восстановление пароля и почтовые уведомления не подключены.

Эта версия использует локальную SQLite и требует постоянного диска. Для публичного
размещения используйте один сервер с Node 24, HTTPS и резервным копированием.
Для Vercel сначала требуется перенос базы на внешний сервис.
Один Telegram-токен обслуживает один polling-процесс: Python-бот либо
необязательный launcher bot.js, но не оба одновременно.
